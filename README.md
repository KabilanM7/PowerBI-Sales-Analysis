 Data Visualization and Storytelling

Project Name
Sales Analysis and Business Insights using Power BI

 Objective
To analyze sales data and create visualizations
that help understand business performance.

 Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX

 Dataset
Sales dataset containing sales, profit,
product and customer information.

Data Cleaning
- Removed duplicate records where appropriate.
- Handled missing values.
- Corrected data types.
- Converted USD values into INR using a documented exchange rate.

 Visualizations
- Total Sales Analysis
- Profit Analysis
- Monthly Sales Trend
- Category Analysis
- Region Analysis
- Sales vs Profit Analysis

 Business Insights
- Identified top-performing products.
- Analyzed sales and profit performance.
- Identified monthly sales trends.
- Provided business recommendations based on data.

 Deliverables
- Power BI Dashboard (.pbix)
- Visual Report (.pdf)
- Dashboard Screenshots

 Conclusion
This project helped me understand data visualization,
business analysis and storytelling using Power BI.
